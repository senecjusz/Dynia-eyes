# Dynia z ruchomymi oczami 🎃

Projekt na Halloween robiony razem z synem: dynia, która rusza oczami. Szczegóły i poziomy realizacji: [docs/projekt.md](docs/projekt.md).

## Struktura

| Folder | Zawartość |
|---|---|
| `cad/` | Eksporty modeli z Onshape (`step/`, `stl/`); źródło prawdy to dokument w Onshape |
| `firmware/` | Kod sterujący oczami |
| `electronics/` | Schematy, lista części, połączenia |
| `docs/` | Notatki, zdjęcia z postępów, decyzje |

## Komputery

- **Kobyłka** – Windows (weekendy)
- **Warszawa** – Linux, Omarchy

Synchronizacja przez zdalne repo Git: przed pracą `git pull`, po pracy `git push`.
