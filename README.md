# Dynia z ruchomymi oczami 🎃

Projekt na Halloween robiony razem z synem: dynia, która rusza oczami. Szczegóły i poziomy realizacji: [30-projekt/opis.md](30-projekt/opis.md).

## Struktura

| Folder | Zawartość |
|---|---|
| [`00-inbox/`](00-inbox/) | Wrzutnia na wszystko – linki, zrzuty, PDF-y, pomysły. Claude to potem rozkłada |
| [`10-inspiracje/`](10-inspiracje/) | Projekty z internetu, na których bazujemy, z notatką co z nich bierzemy |
| [`20-analizy/`](20-analizy/) | Porównania i obliczenia (czujniki, zasilanie, mechanizmy) |
| [`30-projekt/`](30-projekt/) | Opis, poziomy, dziennik decyzji |
| [`40-cad/`](40-cad/) | Eksporty z Onshape (STEP, STL, 3MF) i linki do dokumentów |
| [`50-elektronika/`](50-elektronika/) | Sprzęt, połączenia, schematy |
| [`60-firmware/`](60-firmware/) | Kod dla Arduino Nano |
| [`70-budowa/`](70-budowa/) | Dziennik budowy i zdjęcia |

Numery w nazwach to kolejność „od pomysłu do gotowej dyni” – i porządek sortowania w eksploratorze.

## Komputery

- **Kobyłka** – Windows (weekendy)
- **Warszawa** – Linux, Omarchy

Synchronizacja przez zdalne repo Git: przed pracą `git pull`, po pracy `git push`.
